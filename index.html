    Sistemas que resolvem problemas reais

    dados ilustrativos
    IA · AgenteUso interno

    Jarvis: assistente de voz que consulta o ERP

    Pergunta por voz ou texto, resposta falada com dados reais de vendas, faturamento, notas de entrada, contas a pagar e transferências das 5 lojas.

    Problema
    Toda pergunta de gestão virava um pedido de relatório e uma espera.
    Solução
    LLM com tool calling: a IA escolhe a consulta pronta, que roda nas lojas em paralelo e em modo somente leitura. Os totais são calculados em Python, porque a IA erra contas.
    Resultado
    Respostas em segundos, faladas no navegador, com o consumo de tokens de cada pergunta registrado.
    • Python
    • Flask
    • LLM · Tool calling
    • Web Speech API
    • SQL Server
